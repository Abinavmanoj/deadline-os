# DEADLINE OS – Your Personal Goal Countdown Lock Screen

DEADLINE OS is a personalised countdown lock-screen experience designed to help students and professionals stay focused on their important deadlines.

The application transforms ordinary deadlines into meaningful visual reminders through a live countdown, personalised goals, progress tracking and milestone management.

### Key Features
- Live countdown displaying days, hours, minutes and seconds.
- Customisable goal titles and deadlines.
- Start-date-based progress tracking.
- Interactive milestone management.
- Persistent settings using browser local storage.
- Responsive, modern dark-themed interface.

### Purpose
The goal is to make deadlines more visible and encourage consistent progress towards personal, academic and professional goals.

### Technologies
HTML5, CSS3 and JavaScript.

### Deployment
Hosted using GitHub Pages.

DEADLINE OS makes every second count towards your next achievement.
